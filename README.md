# تمارين JavaScript — الأسبوع الثاني

مجموعة من التمارين التطبيقية لمراجعة مفاهيم JavaScript، مع اختبارات وحدات وملاحظات توثيقية وتقرير أسبوعي.

## محتويات المشروع

| المسار | الوصف |
|---|---|
| `Exercises/` | ملفات التمارين التطبيقية. |
| `Exercises/__tests__/` | اختبارات Jest للتمارين من الأول إلى السادس. |
| `notes/` | التقرير الأسبوعي ومقارنة `let` و`var`. |
| `docs/` | توثيق JSDoc المولّد للتمرين الأول. |

> أسماء المجلدات أعلاه مطابقة لما هو موجود في المستودع، مع اختلاف حالة الأحرف عن الأسماء الواردة في وصف المشروع.

## التمارين

| الملف | الموضوع |
|---|---|
| `Ex1-normalizeNames.js` | تنسيق الأسماء وتطبيعها. |
| `Ex2-calculateCart.js` | حساب عناصر سلة التسوق. |
| `Ex3-groupByStatus.js` | تجميع العناصر حسب الحالة. |
| `Ex4-findDuplicates.js` | العثور على العناصر المكررة. |
| `Ex5-frequency.js` | حساب التكرارات. |
| `Ex6-users-filtering.js` | تصفية المستخدمين. |
| `Ex7-letVsVar.js` | استعراض الفرق بين `let` و`var`. |

## الملاحظات والتوثيق

- `notes/Week 2– End-of-Week Reflection.md`: التقرير الأسبوعي والتأمل في التعلم والتجارب.
- `notes/Ex7-letVsVar.md`: مقارنة بين `let` و`var` من حيث نطاق المتغيرات.
- `docs/Ex1-normalizeNames.js.html`: توثيق التمرين الأول، ويشمل الدوال `normalizeNames` و`capitalize` و`removeNonEnglishLetters`.
- `docs/index.html` و`docs/global.html`: صفحات الفهرس والمرجع العام المولّدة بواسطة JSDoc.

## الاختبارات

توجد اختبارات Jest للتمارين من الأول إلى السادس داخل `Exercises/__tests__/`. لتشغيلها:

```bash
npm test
```

يبدأ الأمر Jest في وضع المراقبة، وفقًا لإعداد المشروع.
